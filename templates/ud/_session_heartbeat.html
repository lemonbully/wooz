{% comment %} Session heartbeat included on every authenticated dashboard/store page. Polls accounts:session_ping on a short interval. When this device's session has been ended from another device (Security → Devices & sessions → Sign out), the row is gone, the ping comes back {authenticated:false}, and the page reloads which, being behind login_required, lands on sign-in. So "end this session" takes effect on the other device within one interval, not on its next navigation. Only polls while the tab is visible, so a backgrounded tab costs nothing. {% endcomment %}
