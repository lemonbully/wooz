{% extends "base.html" %} {% load static %} {% comment %} Universal subscription-renewal wall. Rendered by billing.middleware.SubscriptionRenewalGateMiddleware in place of every owner-dashboard page once a paid subscription has lapsed, so whatever URL the owner opens, this same un-dismissable wall answers and no dashboard data is ever rendered behind it. Two modes: * ``plan`` set (the normal case): the owner renews the plan they had, and only that plan. One plan panel on the left, the renewal checkout (breakdown, optional discount code, agreement, pay) inline on the right. The checkout endpoints (billing.renewal_views) refuse any other slug server-side too. * ``plan`` empty but ``cards`` set: their previous plan was retired, so there is nothing to pin them to. The active plans are listed and selecting one fills the same checkout panel underneath. {% endcomment %} {% block title %}Renew your subscription · OneWooz{% endblock %} {% block head %} {% endblock %} {% block body %}
