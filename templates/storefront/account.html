{% extends store_base|default:"storefront/theme_base.html" %} {% load static %} {% load website_filters %} {% comment %} Storefront customer account ("My Account"). Two layouts from one markup: Desktop (>= 64rem): a profile card + section menu on the left (My Orders, Wishlist, Store Credit, Profile & Addresses, Account Settings, Sign Out) and, on the right, the "My Account" heading, four stat tiles and the open section. Phone / tablet (< 64rem): a greeting card (opens the account menu), 2 x 2 stat tiles, the open section and a fixed bottom bar (Home, Orders, Wishlist, Account). "Account" shows the same menu card the desktop sidebar uses. Sections are deep-linked by hash: #orders #wishlist #credits #profile #settings (#menu on phones; the old #account-details opens Profile). Without JavaScript every section simply shows one after another. My Orders: status chips (GET ?status=, "Returned" = shipment back to seller; phones fold Paid / Delivered / Cancelled / Returned into "More"), instant search by product or order number, one card per order with the first item's photo. Track Order shows only on SHIPPED orders and opens the courier's own tracking page in a new tab (order.track_url, see storefront.account_profile.annotate_order_cards). Profile & Addresses and Account Settings share storefront/_account_profile.html (one copy on the page; its data-ap-part="profile|settings" blocks are shown per section). Look = the D2C themes' own: black + neutral greys only (no brand tint), small uppercase tracked labels, light headings, hairlines, 6px corners; font inherited from the theme (Work Sans). Phones: the Account menu has a Back link. Hooks other code relies on are unchanged: acct-* sign-in ids, data-view-order / order-detail- / order-modal, data-orq-* (storefront/_order_request*.html), data-wish + .wishlist-remove-btn. {% endcomment %} {% block page_content %} {% website_base_path website request as website_base %} {% with sym=website.currency|currency_symbol %}
