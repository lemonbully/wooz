{% load store_extras %} {% comment %} Trusted-badge picker (choose up to 4). `trusted_badges` comes from commerce.trust_badges.options: the platform set (retired badges removed) and the store's own badges, each {name, image, icon, svg, custom}. The value stored on the product is the badge NAME, so a product keeps working as the set changes. The "+" tile opens a popup to create a store badge: a name of at most two words and an icon chosen from the built-in set (commerce.trust_icons; no uploads). It is saved via store:trust_badge_create and added here already ticked. A store badge can be deleted with its ×. Choosing a warranty badge locks the Compliance step's "Guarantee / warranty" field to it. "Returnable" and "Replacement Only" are always offered: ticking one locks the Return policy to match, and only one of the two can be ticked. Wired by initBadgePicker in product_form.html. {% endcomment %}
