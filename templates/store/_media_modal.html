{% comment %} Universal media modal mounted once in the store shell, driven by `static/js/app/media-library.js`. Every media surface (the library page, product galleries, category images, banners, section content) opens this one modal via `window.OneWoozMedia.open({ kind, multiple, onSelect })` or a `[data-ow-media-open]` trigger. Inside it a user uploads a new file or selects an existing one; each item carries Edit and Delete. Config and the CSRF token are rendered by Django onto the root so the script needs no globals. `data-*-tmpl` URLs embed the all-zero UUID as a placeholder the script swaps for the real asset id the only CSP-safe way to hand a reversed URL to JS. {% endcomment %}
