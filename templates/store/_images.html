{% load store_extras %} {% comment %} Product images six fixed blocks. Clicking an empty block (or "Choose from media library") opens the store media library modal, where the owner uploads or picks images; several fill the empty blocks from the one clicked, in order. Each image is submitted as a hidden `media_image` asset id; the view copies the file into a ProductImage server-side (commerce.media_processing.clone_asset_file). Each image stays in its own block: removing one (a hidden `remove_image` input) leaves that block empty, and nothing after it moves up. Saved images go back into the block they were saved in (their `order` is the block number; `image_slot` / `media_image_slot` post it). The first filled block is the main image. Wired by initImageSlots in product_form.html; the cap (6) is enforced server-side too. {% endcomment %}
