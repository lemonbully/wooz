{% comment %} One variant-type row: a variation TYPE plus its VALUES as comma-separated tag chips. The type is picked from common presets (Size, Color, Material, …) or, via "Custom…", typed freely. Either way the name posts as `variant_type_name` (the text input; the picker itself has no name and only drives it), and values post as `variant_type_values` (a comma-joined hidden input the tag widget keeps in sync). The picker is wired by initVariantTypePicker in product_form.html. Include with `name` and `values`. {% endcomment %}
